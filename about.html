Chuyện ngắn gọn về mình

Mình là Fullstack Developer, hiện làm Software Engineer tại FPT Software. Công việc chính của mình gắn với Java, Node.js / NestJS, TypeScript và React / Next.js — từ tầng thiết kế database, xây API cho tới giao diện người dùng.

Mình lớn lên ở Huế và tốt nghiệp Trường Đại học Khoa học Huế. Sở thích lớn nhất ngoài giờ làm là đọc truyện chữ vào buổi tối — cũng chính từ đó mà mình tự tay làm ra web đọc truyện sungthe.online cùng mấy con bot crawl và dịch truyện AI.

Ở nhà mình tự dựng một chiếc Ubuntu Home Server chạy 24/7. Trên đó có web production sungthe.online, các worker chạy bot định kỳ, và OpenClaw tự host để dùng AI hỗ trợ công việc cá nhân. Tự cấu hình Nginx, SSL, PM2/Docker và tự debug khi có lỗi khiến mình chủ động hoàn toàn ở khâu vận hành.

Trong code, mình thích kiến trúc rõ ràng, công nghệ đủ chín và diff nhỏ gọn — không thích viết mấy đoạn code đánh đố người đọc. Chính trang portfolio bạn đang xem cũng chỉ là HTML, CSS và JavaScript thuần, không framework, mở lên là chạy nhẹ tênh.

Cách mình làm việc

Ba nguyên tắc mình luôn giữ qua hầu hết các dự án.

Rõ ràng ngay từ API & dữ liệu

Trước khi viết logic, mình luôn chốt rõ schema và ranh giới API: nhận vào cái gì, trả ra cái gì, và từ chối điều gì. Chặt chẽ từ đầu luôn rẻ hơn rất nhiều so với việc phải sửa lại dữ liệu về sau.

Làm xong là phải chạy thật được

Code chỉ có giá trị khi triển khai lên môi trường thật và người dùng dùng được. Mình ưu tiên thiết lập dễ chạy, có test tự động và quy trình deploy gọn gàng lên Linux server.

Code gọn cho người đọc tiếp theo

Đặt tên rõ nghĩa, tách hàm vừa tay, không lạm dụng abstraction phức tạp. Mình luôn viết cho người đọc sau này — mà thường đó chính là mình sau sáu tháng quay lại sửa bug.
