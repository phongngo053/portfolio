Giới thiệu tổng quan

Tôi là Fullstack Developer với ~2 năm kinh nghiệm, hiện đang làm Software Engineer tại FPT Software từ tháng 11/2024. Công việc hằng ngày của tôi tập trung vào Java, Node.js / NestJS, TypeScript và React / Next.js, bao quát từ thiết kế cơ sở dữ liệu, xây dựng API đến giao diện người dùng.

Tôi sinh sống tại Huế và tốt nghiệp Trường Đại học Khoa học Huế (08/2020 – 06/2024). Điểm mạnh của tôi là chủ động ứng dụng AI vào thực tiễn kỹ thuật: từ tích hợp LLM API (OpenAI, DeepSeek), xây dựng pipeline dịch thuật tự động giữ ngữ cảnh cho nền tảng web truyện sungthe.online, đến triển khai AI Agent (OpenClaw) phục vụ tự động hóa công việc hằng ngày.

Tôi tự duy trì một máy chủ Ubuntu Home Server hoạt động 24/7 để vận hành web truyện production, các worker thu thập và xử lý ngôn ngữ bằng AI theo lịch, cùng trợ lý AI Agent nội bộ. Việc trực tiếp cấu hình Nginx, chứng chỉ SSL, PM2/Docker và xử lý sự cố thực tế giúp tôi chủ động hoàn toàn ở khâu triển khai và vận hành.

Khi viết mã nguồn, tôi ưu tiên kiến trúc rõ ràng, công nghệ ổn định và cách tiếp cận đơn giản, dễ bảo trì thay vì làm phức tạp hóa vấn đề. Ngay cả trang portfolio này cũng được tôi xây dựng hoàn toàn bằng HTML, CSS và JavaScript thuần, không phụ thuộc framework để đảm bảo tốc độ tải nhanh và gọn nhẹ.
