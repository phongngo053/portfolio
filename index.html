Code chạy trên localhost mới chỉ là một nửa — phần thú vị nhất là đưa nó chạy ổn định ngoài đời thật.

Mình bắt đầu từ việc tự học làm web rồi đi theo con đường kỹ sư phần mềm. Công việc hằng ngày xoay quanh Java, Node.js / NestJS, TypeScript và React / Next.js — nhưng thay vì chỉ dừng ở một lớp backend hay frontend, mình thích nắm trọn từ thiết kế dữ liệu, API cho tới giao diện và khâu triển khai.

Ở nhà mình duy trì một chiếc Ubuntu Home Server để tự host các sản phẩm cá nhân: từ nền tảng đọc truyện sungthe.online, dàn bot tự động crawl và dịch truyện bằng AI, cho tới self-host trợ lý AI (OpenClaw) hỗ trợ công việc hằng ngày.

Ngoài giờ code, mình mê đọc truyện chữ — và phần lớn những sản phẩm mình tự xây cũng xuất phát từ chính thói quen đó.
