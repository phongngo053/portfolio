I build the invisible layer — the APIs, services and pipelines that keep a product moving.

I started out as a self-taught developer poking at the web, and turned it into a career as a backend engineer. These days I work mostly in Java and Node.js / NestJS, writing services that other people can build on without fearing them.

I like the unglamorous work: schema design, idempotent consumers, sensible error messages, a deploy that doesn't wake anyone up. But I also like the side projects — a Chrome extension that reads quiz questions off the screen, a YouTube player with live Vietnamese subtitles, a portable dev environment you can drop onto any USB stick.

Away from the editor I read a lot of novels, and I write software for people who share that habit.
